# 🚓 경찰청 운영 규정

> 경찰의 의무·지휘·검문·수색·체포·추격·무력 사용과 내부 책임 기준입니다.

{% hint style="danger" %}
경찰 권한은 시민 보호와 공정한 법 집행을 위해서만 사용합니다.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 기본 원칙과 지휘 | 제80조~제83조 |
| 02 | 검문 수색 압수 | 제84조~제89조 |
| 03 | 체포 구금 벌금 | 제90조~제94조 |
| 04 | 추격과 무력 사용 | 제95조~제101조 |
| 05 | 금지 행위와 내부 책임 | 제102조~제108조 |

## ✅ 핵심 확인

- 검문·수색에는 합리적 근거가 필요합니다.
- 체포 사유와 주요 혐의를 고지합니다.
- 무력은 낮은 단계부터 비례적으로 사용합니다.
- 부패·편파·정보 유출은 중대한 권한 남용입니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
