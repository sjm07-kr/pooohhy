# 📮 신고·증거·복구

> 신고 접수·기한·당사자·영상·로그·증거 부족·허위 신고 처리 기준입니다.

{% hint style="info" %}
공개 박제보다 앞뒤 맥락이 포함된 원본 증거를 공식 티켓으로 제출하세요.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 신고 | 제288조~제292조 |
| 02 | 증거 | 제293조~제299조 |
| 03 | 판단 | 제300조~제303조 |

## ✅ 핵심 확인

- 일반 RP 신고는 72시간 이내를 원칙으로 합니다.
- 영상·스크린샷·로그의 한계를 함께 봅니다.
- 신고자에게도 위반이 있으면 따로 판단합니다.
- 증거 부족은 허위 신고를 뜻하지 않습니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
