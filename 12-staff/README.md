# 👑 운영진 직급 및 권한

> 총관리자부터 뉴비도우미까지 직급별 의무·권한·기록·징계 기준입니다.

{% hint style="warning" %}
운영진도 규정의 적용을 받으며 본인·지인·소속 팩션 사건에서 회피해야 합니다.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 직급과 기본 의무 | 제261조~제267조 |
| 02 | 중립 비밀 개인정보 | 제268조~제270조 |
| 03 | 권한 사용 | 제271조~제279조 |
| 04 | 사건 처리와 책임 | 제280조~제287조 |

## ✅ 핵심 확인

- 직급은 인격적 우월이 아니라 책임 범위입니다.
- 운영정보와 개인정보를 보호합니다.
- 권한 사용은 대상·사유·범위를 기록합니다.
- 오제재는 즉시 정정하고 가능한 원상회복을 합니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
