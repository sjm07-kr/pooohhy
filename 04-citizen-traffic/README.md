# 🏙️ 시민법 및 교통법

> 경찰이 적용할 수 있는 범죄 구성 요건과 차량·도로 RP 기준입니다.

{% hint style="warning" %}
인게임 구금·벌금과 서버 운영 제재는 서로 다른 절차입니다.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 통칙 | 제54조~제57조 |
| 02 | 생명 신체 자유에 관한 범죄 | 제58조~제65조 |
| 03 | 재산 거래에 관한 범죄 | 제66조~제72조 |
| 04 | 공공질서와 경찰 관련 범죄 | 제73조~제79조 |
| 05 | 교통질서 | 제144조~제148조 |
| 06 | 추격과 차량 무력 | 제149조~제151조 |
| 07 | 차량 현실성 | 제152조~제156조 |

## ✅ 핵심 확인

- 범죄명·구성 요건·등급을 함께 확인합니다.
- 미수·경합·정당한 방어를 구분합니다.
- 차량 종류와 파손 상태에 맞게 운전합니다.
- 추격 중에도 VDM·Fail Driving은 금지됩니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
