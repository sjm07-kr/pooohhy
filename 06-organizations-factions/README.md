# 🤝 범죄조직 및 팩션

> 조직 창설·동맹·적대·전쟁과 팩션장·사업권·구역·재산 운영 기준입니다.

{% hint style="warning" %}
경찰청·흑사회·신사회·푸우클럽 등 모든 팩션에 공정한 공통 기준을 적용합니다.
{% endhint %}

|---:|---|---|
| 01 | 조직의 지위 | 제109조~제113조 |

## ✅ 핵심 확인

- 임시 팩션 5명, 정식 팩션 10명을 기본으로 합니다.
- 조직전은 승인된 시간·장소·인원을 지킵니다.
- 민간인·뉴비·중립 팩션 개입을 제한합니다.
- 팩션 권한과 공용 재산의 사적 사용을 금지합니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
