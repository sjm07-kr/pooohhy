# 📘 총칙 및 기본 원칙

> 규정의 목적·적용 대상·용어·해석·운영 판단과 개정 기준을 안내합니다.

{% hint style="info" %}
모든 세부 규정은 총칙의 공정성·비례성·증거 원칙에 따라 해석합니다.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 기본 규정 | 제1조~제10조 |
| 02 | 운영 판단 | 제11조~제15조 |

## ✅ 핵심 확인

- 현실과 인게임을 분리합니다.
- 규정을 몰랐다는 이유만으로 자동 면제되지 않습니다.
- 모호한 사안은 이용자에게 과도하게 불리하게 해석하지 않습니다.
- 중대한 변경은 공식 채널과 GitBook에 공지합니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
