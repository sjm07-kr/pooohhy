# 📎 부록 1. 주요 RP 용어 정리

> 운영 중 빠르게 확인할 수 있도록 핵심 기준을 표와 절차로 정리했습니다.

{% hint style="info" %}
이 부록은 빠른 참고용입니다. 구체적인 사건 판단에서는 본문 조항과 원본 증거를 함께 확인합니다.
{% endhint %}

| 용어 | 뜻 | 핵심 기준 |
|---|---|---|
| IC | 캐릭터 안의 말·행동·정보 | 캐릭터가 실제로 얻은 정보만 사용 |
| OOC | 현실 이용자 차원의 대화·정보 | RP 이득에 사용 금지 |
| RP | 캐릭터와 세계관에 맞춘 역할 수행 | 상대의 대응 기회와 결과 존중 |
| MG | 외부 정보를 캐릭터가 사용 | 방송·디스코드·다른 캐릭터 정보 금지 |
| PG | 비현실적 결과를 일방 강제 | 시스템 가능 여부와 별개로 금지 |
| Fail RP | 개연성·부상·환경을 무시 | 반복·악의성에 따라 제재 |
| RDM | 충분한 이유·상호작용 없는 공격 | 자기방어 등 즉각적 예외만 인정 |
| VDM | 차량을 사람 공격 무기로 사용 | 탈출을 위한 최소 충돌은 개별 판단 |
| NLR | 사망 사건 기억·복귀 제한 | 사망 장소·가해자·직전 정보 상실 |
| Revenge Kill | 사망 후 이전 가해자에게 보복 | 새로 얻은 정보라도 이전 기억 복원 금지 |
| Combat Logging | 불리한 RP 중 접속 종료 | 오류면 10분 내 복귀·알림 |
| Fear RP | 즉각적 위해 앞에서 공포 표현 | 현실적인 탈출 가능성은 인정 |
| Value of Life | 캐릭터 생명을 우선 | 사소한 이득 위한 자살성 행동 금지 |
| Fail Driving | 차량 한계를 무시한 운전 | 슈퍼카 산악, 전복 후 즉시 주행 등 |
| Cop Baiting | 목적 없이 경찰 반응 유도 | 실제 범죄 계획의 합리적 유인은 예외 |
| Stream Sniping | 방송 정보로 접근·회피·공격 | 방송 참여 이벤트 외 금지 |
| Ghosting | 사망·관전 정보 전달 | 살아 있는 캐릭터에게 전달 금지 |
| Perma Death | 캐릭터 서사의 영구 종료 | 본인 동의 또는 승인 절차 필요 |
| Power Abuse | 직업·운영 권한 사적 사용 | 개인·지인·팩션 이익 사용 금지 |
| Exploit | 버그·시스템 허점을 고의 이용 | 발견 즉시 중단·비공개 신고 |
| Duplication | 돈·아이템·차량의 비정상 복제 | 생성·유통·은닉 모두 제재 |
| Ban Evasion | 계정·VPN·타인을 이용한 제재 회피 | 관련 계정 통합 제재 가능 |
| PK | 일반적인 캐릭터 사망 처리 | 보통 NLR 적용, 영구 사망 아님 |
| CK | 합의·승인된 영구 사망 | 재산·직위·관계 정리 필요 |
| Safe Zone | 지정된 보호·필수 이용 구역 | 범죄 회피 수단으로 진입 금지 |
| OOC 중재 | 기술·규정 문제를 현실 이용자 차원에서 해결 | 필요한 최소 대화 후 RP 복귀 |

{% hint style="info" %}
용어의 짧은 뜻보다 본문의 구성 요건·예외·사례·제재 기준이 우선합니다.
{% endhint %}
