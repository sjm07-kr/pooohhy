# 📎 부록 4. 운영진 권한 및 직급별 처리 가능 범위

> 운영 중 빠르게 확인할 수 있도록 핵심 기준을 표와 절차로 정리했습니다.

{% hint style="info" %}
이 부록은 빠른 참고용입니다. 구체적인 사건 판단에서는 본문 조항과 원본 증거를 함께 확인합니다.
{% endhint %}

## 직급별 기본 범위

| 직급 | 주요 업무 | 단독 처리 가능 | 상급 승인 필요 |
|---|---|---|---|
| 총관리자 | 정책·보안·인사·최종 제재 | 전 범위 최종 승인 | 자기 사건은 독립 검토 필요 |
| 운영자 | 운영 전반·팩션·장기 사건 | 90일 이내 제한, 광범위 회수 권고·집행 | 영구 제한, 전면 초기화, 강제 해체 |
| 관리자 | 신고·복구·중기 제재 | 14일 이내 제한, 부분 재산 회수, 팩션 경고 | 14일 초과, 전면 초기화, 팩션 정지·해체 |
| 인게임관리자 | 실시간 중재·핵 초동·복귀 | 킥, 24시간 이내 임시 제한, 현장 복구 건의 | 확정 장기 제재, 대규모 회수 |
| 스태프 팀장 | 스태프 교육·티켓·초동 품질 | 안내, 공식 경고, 제한된 킥, 사건 이관 | 이용 제한 확정, 재산·팩션 처분 |
| 스태프 | 안내·증거 수집·당사자 분리 | 안내, 구두 경고, 승인 범위 킥 | 공식 장기 조치 전부 |
| 뉴비도우미 | 뉴비 안내·교육 | 도움, 자료 연결, 긴급 보고 | 경고·킥·밴·재산·팩션 조치 전부 |

## 행위별 최소 권한

| 조치 | 최소 실행 직급 | 필수 기록·검토 |
|---|---|---|
| 구두 안내 | 뉴비도우미 | 반복 시 메모 권장 |
| 공식 경고 | 스태프 | 조항·증거·담당자 기록 |
| 킥 | 스태프 | 사유·시각 기록 |
| 24시간 임시 제한 | 인게임관리자 | 증거 보존·관리자 보고 |
| 14일 이하 확정 제한 | 관리자 | 사건 기록·통지 |
| 15~90일 제한 | 운영자 | 상급 검토 권장 |
| 영구 이용 제한 | 총관리자 또는 지정 2인 합의 | 독립 검토·이의 절차 필수 |
| 부분 재산 회수 | 관리자 | 전후 재산·근거 기록 |
| 광범위 재산 회수 | 운영자 | 로그·범위 검토 |
| 전면 캐릭터 초기화 | 총관리자 | 분리 불가능성·2인 검토 |
| 팩션 경고 | 관리자 | 개인·집단 책임 구분 |
| 팩션 일시 정지 | 운영자 2인 검토 | 기간·해제 조건 통지 |
| 팩션 강제 해체 | 총관리자 | 소명 기회·재산 정리 계획 |
| 운영진 임시 권한 정지 | 관리자 이상 | 긴급 근거·상급 보고 |
| 운영진 해임 | 총관리자 또는 인사권자 | 조사·소명·권한 회수 |
| 대규모 서버 롤백 | 총관리자 또는 가용 최고책임자 | 영향·백업·사후 공지 |

## 공통 제한

1. 시스템상 버튼이 보이는 것은 사용 권한을 뜻하지 않는다.
2. 본인·지인·소속 팩션 사건은 긴급 보존조치 외에 최종 판단에서 회피한다.
3. 텔레포트, 관전, 부활, 생성, 정보 조회 등 모든 민감 권한은 업무 목적으로만 사용한다.
4. 긴급조치는 7일 이내 사후 검토한다.
5. 오제재 확인 시 즉시 중단·기록 정정·가능한 복구를 한다.
