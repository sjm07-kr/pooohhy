# 🚗 재산·아이템·서버 시스템

> 차량·돈·아이템·창고·팩션 재산과 리붓·크래시·복구 신청 기준입니다.

{% hint style="warning" %}
추격·수사·리붓 직전에 재산이나 상태를 옮겨 결과를 피해서는 안 됩니다.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 재산의 구분과 관리 | 제222조~제226조 |
| 02 | 이전과 비정상 재산 | 제227조~제231조 |
| 03 | 복구 | 제232조~제233조 |
| 04 | 리붓 전후 행동 | 제234조~제237조 |
| 05 | 비정상 종료와 오류 | 제238조~제241조 |
| 06 | 증거와 손해 | 제242조~제244조 |

## ✅ 핵심 확인

- 개인 재산과 팩션 재산을 구분합니다.
- 부계정·캐릭터 간 재산 이전을 금지합니다.
- 리붓은 진행 중인 사건을 자동 종료하지 않습니다.
- 복구에는 시각·품목·원인과 증거가 필요합니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
