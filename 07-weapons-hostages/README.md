# 🔫 총기·납치·강도·인질 RP

> 무기 소지·사용부터 납치 조건·인질 협상·은행강도·총격 전환 기준까지 안내합니다.

{% hint style="danger" %}
총기는 최후수단이며, 자작 인질과 이유 없는 납치는 허용되지 않습니다.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 소지와 관리 | 제157조~제159조 |
| 02 | 무기 사용 | 제160조~제165조 |
| 03 | 범죄 시스템 관련 무기 | 제166조~제169조 |
| 04 | 공통 원칙 | 제170조~제171조 |
| 05 | 납치 | 제172조~제176조 |
| 06 | 인질 | 제177조~제180조 |
| 07 | 강도 콘텐츠 | 제181조~제186조 |

## ✅ 핵심 확인

- 사소한 말다툼만으로 발포할 수 없습니다.
- 납치에는 구체적인 캐릭터 목적이 필요합니다.
- 인질에게 반응과 협상의 기회를 보장합니다.
- 강도별 경찰·범죄 인원 조건을 확인합니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
