# 💬 커뮤니티·개인정보·방송

> 인게임 음성·채팅·디스코드 질서와 개인정보·방송·스트리밍 기준입니다.

{% hint style="danger" %}
성희롱·현실 협박·개인정보 공개는 RP라는 이유로 정당화할 수 없습니다.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 의사소통 기본 원칙 | 제198조~제203조 |
| 02 | 채널 질서 | 제204조~제209조 |
| 03 | 음성 미디어 | 제210조~제212조 |
| 04 | 현실 개인정보 | 제349조~제353조 |
| 05 | 방송 영상 스트리밍 | 제354조~제359조 |

## ✅ 핵심 확인

- 캐릭터 욕설과 현실 이용자 모욕을 구분합니다.
- 도배·광고·사칭·음악 테러를 금지합니다.
- 현실 개인정보를 수집·공개하지 않습니다.
- 방송으로 얻은 정보를 인게임에 사용하지 않습니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
