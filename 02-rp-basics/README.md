# 🎭 RP 기본법

> MG·PG·RDM·VDM·NLR·Combat Logging 등 핵심 RP 위반을 세부 유형별로 확인합니다.

{% hint style="danger" %}
다른 이용자의 대응 기회와 이야기의 연속성을 무너뜨리는 행동은 엄격하게 처리합니다.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 정보와 역할의 경계 | 제16조~제20조 |
| 02 | 행동 강요와 현실성 | 제21조~제26조 |
| 03 | 무차별 공격과 보복 | 제27조~제30조 |
| 04 | 상황 이탈과 회피 | 제31조~제34조 |
| 05 | 계정 프로그램 시스템 | 제35조~제40조 |

## ✅ 핵심 확인

- 외부 정보를 캐릭터가 사용하면 MG입니다.
- 상대에게 결과를 일방 강요하면 PG입니다.
- 정당한 이유 없는 공격은 RDM·VDM입니다.
- 사망·튕김·재접속 규칙을 반드시 지킵니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
