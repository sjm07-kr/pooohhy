# 🏥 부상·사망·의료 RP

> 쓰러짐·중상·EMS·부활·기억·현장 복귀와 시체 RP 기준입니다.

{% hint style="info" %}
사망 후 같은 사건에 복귀하거나 외부 정보로 가해자를 추적하면 NLR 위반입니다.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 상태 구분 | 제187조~제188조 |
| 02 | 구조와 치료 | 제189조~제192조 |
| 03 | 기억과 복귀 | 제193조~제197조 |

## ✅ 핵심 확인

- 부상 원인에 맞는 행동 제한을 표현합니다.
- 다운 상태에서 전술 정보를 전달하지 않습니다.
- EMS가 있으면 의료 RP에 협조합니다.
- 병원 부활 후 같은 사건으로 돌아가지 않습니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
