# ⚖️ 제재·재심·분쟁 처리

> 단계별 제재·보조조치·가중·감경·밴 회피·이의제기와 분쟁 절차입니다.

{% hint style="info" %}
제재는 위반 중단·재발 방지·피해 회복을 목적으로 비례적으로 적용합니다.
{% endhint %}

## 📚 세부 페이지

| 순서 | 페이지 | 포함 범위 |
|---:|---|---|
| 01 | 제재 단계 | 제304조~제310조 |
| 02 | 보조 제재 | 제311조~제315조 |
| 03 | 적용 원칙 | 제316조~제318조 |
| 04 | 가중 | 제319조~제325조 |
| 05 | 감경 | 제326조~제329조 |
| 06 | 제재 회피 | 제330조~제335조 |
| 07 | 이의제기 | 제336조~제338조 |
| 08 | 재심 | 제339조~제342조 |
| 09 | 분쟁 처리 | 제343조~제348조 |

## ✅ 핵심 확인

- 구두 안내부터 영구 제한까지 6단계로 구분합니다.
- 재산 회수·팩션 조치·권한 회수를 병과할 수 있습니다.
- 초범·자진 신고·피해 복구는 감경됩니다.
- 기존 제재자가 재심을 단독 담당하지 않습니다.

## 🧭 이용 방법

1. 왼쪽 메뉴에서 필요한 장을 선택합니다.
2. 해당 조문의 정의·금지행위·예외·사례·제재를 함께 확인합니다.
3. 실제 사건은 증거와 전후 맥락, 가중·감경 사유를 종합합니다.
4. 판단이 어려우면 공개 논쟁보다 공식 문의 티켓을 이용합니다.
